# **종합설계**

## 프로젝트 목표

본 프로젝트는 여러 가족 구성원이 번갈아 고령자를 돌보는 과정에서 발생하는 정보 단절을 줄이기 위한 통합 돌봄 관리 플랫폼 **‘Family Care Cloud’**를 개발하는 것을 목표로 한다. 병원 방문 기록, 복약 여부, 식사 상태, 생활 변화, 주요 일정 등의 돌봄 정보를 하나의 웹에서 저장·관리할 수 있도록 하고, AI 분석 기능을 활용하여 최근 돌봄 기록을 자동으로 정리해 다음 보호자에게 필요한 인수인계 정보를 제공한다.

이를 통해

- 가족 간 돌봄 정보 누락 및 반복 확인 감소
- 보호자 교대 시 빠르고 정확한 Care Handoff 지원
- 고령자의 병원·복약·생활 기록을 한곳에서 체계적으로 관리
- 장기간 누적된 돌봄 기록을 기반으로 주요 변화와 확인사항 파악
- 가족 구성원 간 돌봄 역할과 커뮤니케이션 효율 향상을 동시에 달성하는 것을 목표로 한다.

## 프로젝트 기능

본 프로젝트는 **5가지 핵심 기능**으로 구성된다.

### ① Care Timeline 기반 통합 돌봄 기록 관리

- 병원 방문, 식사, 복약, 귀가, 돌봄센터 이용, 특이사항 등의 돌봄 기록을 하나의 웹에서 통합 관리
- 보호자가 직접 기록한 내용과 시스템에서 발생한 이벤트를 시간순으로 정리
- 누가, 언제, 어떤 돌봄을 수행했는지 확인 가능
- 과거 기록을 누적하여 고령자의 생활 및 돌봄 이력을 지속적으로 관리

예시

`08:30 돌봄센터 차량 탑승 → 16:30 귀가 → 18:40 저녁 식사 → 20:00 복약 확인`

---

### ② AI Care Handoff 기반 보호자 인수인계

- 최근 Care Timeline에 저장된 돌봄 기록을 AI가 자동으로 분석
- 다음 보호자가 알아야 할 내용을 **건강 / 생활 / 확인 필요사항**으로 구분하여 요약
- 보호자가 일일이 이전 기록을 모두 읽지 않아도 최근 돌봄 상황을 빠르게 파악할 수 있도록 지원
- 중요한 일정, 생활 변화, 반복적으로 나타나는 특이사항 등을 정리하여 제공

예시

> 건강: 최근 병원 방문 후 약 변경 없음
> 
> 
> 생활: 식사 및 복약 정상
> 
> 확인 필요: 최근 일정 관련 반복 질문 증가
> 
> 다음 확인: 토요일 병원 일정
> 

---

### ③ 담당 보호자 및 가족 공동 돌봄 관리

- 이번 주 담당 보호자와 다음 담당 보호자를 지정하여 현재 돌봄 책임자를 명확히 관리
- 가족 구성원이 동일한 고령자의 돌봄 정보를 공동으로 확인
- 담당 보호자가 교대될 때 AI Care Handoff를 통해 이전 돌봄 상황을 전달
- 가족별 역할과 돌봄 순서를 관리하여 돌봄 공백을 최소화

예시

> 이번 주 담당: 아버지
> 
> 
> 다음 주 담당: 삼촌
> 

---

### ④ 일정 및 중요 요청 승인 관리

- 병원 방문, 가족 방문, 돌봄센터 이용 등의 주요 일정을 등록하고 관리
- 일정 상태를 예정 / 완료 / 취소로 구분하여 확인
- 고령자가 일정 취소나 변경과 같은 중요한 요청을 할 경우 담당 보호자에게 승인 요청 전달
- AI가 중요한 의료·돌봄 결정을 직접 수행하지 않고 보호자가 최종 판단하도록 설계

예시

> “이번 주 병원 안 갈래.”
> 
> 
> → 병원 일정 취소 요청 생성
> 
> → 보호자에게 승인 요청
> 
> → `일정 유지 / 취소 승인 / 전화하기`
> 

---

### ⑤ AI 음성 도우미 및 생활 상태 확인

- 고령자가 복잡한 웹 화면을 직접 조작하지 않아도 음성으로 주요 정보를 확인할 수 있도록 지원
- “다음 병원 언제야?”, “오늘 누가 와?”, “약 언제 먹어?”와 같은 질문을 자연어로 입력
- AI가 임의로 답을 생성하지 않고 Cloud DB에 저장된 실제 일정과 돌봄 정보를 조회하여 응답
- 향후 위치 및 생활 패턴 데이터와 연동하여 평소와 다른 이동이나 생활 상태가 감지되면 보호자에게 알림 제공

예시

> 고령자: “이번 주 병원 언제 가?”
> 
> 
> AI: “이번 주 토요일 오전 10시에 내과 진료가 예정되어 있습니다.”
> 

## 접근 방법 및 도구

---

### 1. 시스템 아키텍처 설계

- 웹 기반의 클라이언트-서버 구조로 설계
- **Frontend : Web**
    - 보호자 대시보드
    - Care Timeline
    - AI Care Handoff
    - 일정 및 담당 보호자 관리
    - 승인 요청 화면
- **Backend : AWS 기반 RESTful API 서버**
    - Amazon API Gateway를 통해 Frontend와 Backend 연결
    - AWS Lambda를 활용하여 돌봄 기록 생성·조회, 일정 관리, 담당 보호자 변경 등의 기능 처리
- 병원 방문, 복약, 식사, 일정, 특이사항 등 돌봄 데이터를 Cloud에서 통합 관리

기본 구조:

**Web → API Gateway → Lambda → DynamoDB**

AI 기능 사용 시:

**Lambda → Amazon Bedrock → AI 분석 결과 → Web**

---

### 2. 돌봄 기록 및 Care Timeline 구축

- 보호자가 웹에서 병원 방문, 복약 여부, 식사 상태, 생활 변화, 특이사항 등을 직접 입력
- 입력된 정보를 Amazon DynamoDB에 저장
- 저장된 돌봄 기록을 시간순으로 정렬하여 Care Timeline 형태로 제공
- 기록 작성자, 기록 시간, 기록 유형을 함께 저장하여 누가 어떤 돌봄을 수행했는지 확인 가능
- 일정 데이터는 예정 / 완료 / 취소 상태로 관리

주요 데이터:

- 병원 방문 기록
- 복약 확인
- 식사 상태
- 생활 특이사항
- 돌봄센터 이용
- 주요 일정
- 담당 보호자

---

### 3. AI Care Handoff 시스템 구축

- **Amazon Bedrock 기반 생성형 AI 활용**
- 최근 일정 기간의 Care Timeline 데이터를 AI에 전달
- 보호자가 직접 작성한 자연어 기록을 읽고 중요한 내용을 자동으로 정리
- 다음 보호자에게 필요한 정보를 건강 / 생활 / 일정 / 확인 필요사항 형태로 요약

입력 데이터:

- 최근 병원 방문 기록
- 복약 및 식사 기록
- 생활 변화
- 일정
- 보호자가 작성한 특이사항

출력 데이터:

- 최근 주요 돌봄 상황
- 생활 및 건강 변화
- 다음 일정
- 다음 보호자가 확인해야 할 사항

예시:

> 최근 내과 방문 완료
> 
> 
> 약 변경 없음
> 
> 식사량 감소 기록 2회
> 
> 다음 진료 시 혈액검사 예정
> 
> → 다음 보호자는 식사 상태 확인 필요
> 

---

### 4. 사용자 및 가족 공동 돌봄 관리

- 고령자 1명을 기준으로 여러 가족 보호자가 하나의 Care Group에 참여
- 이번 주 담당 보호자와 다음 담당 보호자를 지정
- 담당 보호자가 변경되면 최근 Care Handoff를 확인할 수 있도록 구성
- 보호자별로 작성한 기록과 담당 이력을 관리
- 향후 Amazon Cognito 등을 활용하여 사용자 인증 및 접근 권한 관리 가능

사용자 유형:

- 고령자
- 가족 보호자

초기 MVP에서는 가족 보호자 중심으로 구현하고, 고령자 전용 화면은 이후 확장할 수 있음.

---

### 5. 일정 및 승인 요청 관리

- 병원 방문, 가족 방문, 돌봄 일정 등을 웹에서 등록
- 일정 상태를 `예정 / 완료 / 취소`로 관리
- 중요한 일정 변경이나 취소 요청이 발생하면 담당 보호자에게 확인 요청
- AI가 의료·복약·중요 일정에 대한 최종 판단을 직접 수행하지 않도록 설계
- 보호자가 승인 / 거절 / 유지 여부를 결정

예시:

**“이번 주 병원 안 갈래.”**

→ 일정 취소 요청 생성

→ 담당 보호자에게 전달

→ 보호자가 `일정 유지 / 취소 승인 / 전화하기` 선택

---

### 7. 인증 및 보안 설계

- 사용자별 로그인 및 가족 그룹 단위 접근 권한 적용
- 동일한 Care Group에 등록된 보호자만 해당 고령자의 돌봄 기록에 접근 가능
- 의료·생활 정보가 포함되므로 개인정보 보호를 고려하여 설계
- 향후 Amazon Cognito를 활용한 인증 기능 적용 가능
- 민감한 의료 판단이나 복약 변경은 AI가 직접 수행하지 않고 보호자에게 확인 요청

---

### 8. 향후 확장 기술

초기 MVP 이후에는 다음 기능을 확장할 수 있다.

- **Amazon Transcribe** : 고령자 음성을 텍스트로 변환
- **Amazon Polly** : AI 답변을 음성으로 제공
- **EventBridge** : 일정 및 정기 알림 처리
- **SNS / Push Notification** : 보호자 알림 전송
- 위치 데이터 기반 생활 패턴 및 이상 이동 감지

AI를 활용해 치매 환자 보호자에게 의료기관 추천, 재정지원 안내, 법률문서 작성 등 다양한 의사결정을 지원하는 기술이다. Family Care Cloud는 의료·재정·법률 정보 제공보다는 **가족이 실제로 수행한 돌봄 기록을 축적하고 다음 보호자에게 인수인계하는 과정**에 차이가 있다.

여러 보호자가 고령자의 일정·활동·복약 등을 공동으로 관리하고 돌봄 일정을 조정하는 플랫폼이다. 담당 보호자와 일정 관리라는 측면에서 본 프로젝트와 유사성이 높다. 따라서 Family Care Cloud는 단순 일정 공유보다 **누적된 Care Timeline을 AI가 읽고 교대 시점에 필요한 정보만 자동 생성하는 기능**을 핵심 차별점으로 둘 필요가 있다.

- **가족 보호자** : 병원·복약·식사·일정 등 흩어진 돌봄 정보를 한곳에서 확인하여 정보 누락과 반복 확인 감소
- **다음 보호자** : AI Care Handoff를 통해 이전 돌봄 상황과 확인해야 할 내용을 빠르게 파악하여 원활한 돌봄 교대 가능
- **고령자** : 가족 간 정보 공유가 원활해져 반복 설명이나 일정 혼선을 줄이고 보다 연속적인 돌봄 지원 가능
- **가족 전체** : 담당 보호자와 주요 일정을 공유하여 돌봄 역할과 책임을 명확하게 관리
